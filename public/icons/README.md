# Home page icons

`feather/` contains unmodified SVG assets from [Feather v4.29.2](https://github.com/feathericons/feather/tree/v4.29.2/icons), distributed under the included MIT license. These files are served locally without a runtime library or external requests.

`google.svg` reuses the Google sign-in mark already present in `components/screens/AccountScreen.js`.
